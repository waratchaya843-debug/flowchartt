เรื่อง: การออกแบบอัลกอริทีมสำหรับระบบธุรกิจ (Flowchart & Pseudocode) ชื่อ-สกุล นางสาว วรัชยา เมืองแทน รหัสประจำตัว 67219030008 ปวช3. จุดประสงค์การเรียนรู้: 1. วิเคราะห์ขั้นตอนการทำงานของโปรแกรมจากโจทย์ปัญหาที่กำหนดได้ 2. เขียนรหัสเทียม (Pseudocode) และผังงาน (Flowchart) เพื่อแก้ปัญหาทางธุรกิจเบื้องต้นได้ 3. ปฏิบัติงานร่วมกับผู้อื่นด้วยความรับผิดชอบและตรงต่อเวลา ตอนที่ 1: พบหวนสัญลักษณ์ผังงาน (Flowchar) จงจับคู่หรือเดิมชื่อและหน้าที่ของสัญลักษณ์พังงานต้อไปนี้ให้ถูกต้อง (อ้างอิงมาตรฐาน ANSI) 1. สัญลักษณ์: วงรีขอบมน (Terminal) หน้าที่การทำงาน: ตอบ ใช้แสดงจุดเริ่มต้นและจุดสิ้นสุดของการทำงาน start /end 2. สัญลักษณ์: สี่เหลี่ยมด้านขนาน (Input/Output) หน้าที่การทำงาน: ตอบ ใช้แสดงการรับข้อมูลเข้าและการแสดงผลข้อมูลออก 3. สัญลักษณ์: สี่เหลี่ยมขนมเปียกปูน(Decision)หน้าที่การทำงาน: ตอบ ใช้แสดงการตัดสินใจหรือเงื่อนไข โดยมีทางเลือก เช่น จริง/เท็จ (false/true) 4. สัญลักษณ์: สี่เหลี่ยมผืนผ้า (Procoss)หน้าที่การทำงาน: ตอบ ใช้แสดงขั้นตอนการประมวลผลหรือการคำนวณ ตอนที่ 2 การออกแบบอัลกอริทีมเพื่อแก้ปัญหาทางธุรกิจโจทย์สถานการณ์ที่ 1: ระบบคิดเงินและส่วนลดร้านสะดวกซื้อ รายละเอียด: ร้านสหกรณ์วิทยาลัย ต้องการโปรแกรมดำนวณราคาสินค้า โดยมีเงื่อนไขว่า ให้ผู้ใช้ป้อนข้อมูล ราคาสินค้าต่อชิ้น และจำนวนชิ้น จากนั้นโปรแกรมจะคำนวณราคารวม หากราคารวมมีมูลค่า ตั้งแต่ 500 บาทขึ้นไป จะได้รับส่วนลดทันที่ 50 บาท หากไม่ถึง 500 บาท จะไม่ได้รับส่วนลด และสุดท้ายให้โปรแกรมแสดงผลราคา 1. การวิเคราะห์ปัญหา (Problem Analysis) ข้อมูลเข้า (Input) ตอบ ราคาสินค้าต่อชิ้น จำนวนชิ้น กระบวนการ (Process) ตอบ คำนวณราคารวมจากราคาสินค้าต่อชิ้นคูณจำนวนชิ้น หากราคารวมตั้งแต่ 500 บาทขึ้นไป ให้ส่วนลด 50 บาท หากไม่ถึง 500 บาท จะไม่ได้รับส่วนลด จากนั้นคำนวณราคาสุทธิหลังหักส่วนลด ข้อมูลออก (Output) ตอบ แสดงราคาสุทธิที่ลูกค้าต้องชำระหลังหักส่วนลด 2. เขียนรหัสเทียม (Pseudocode) BEGIN // เติมคำสั่งให้สมบูรณ์ INPUT ราคาสินค้าต่อชิ้น INPUT จำนวนชิ้น COMPUTE ราคารวม = ราคาสินค้าต่อชิ้น * จำนวนชิ้น IF ราคารวม >= 500 THEN COMPUTE ส่วนลด = 50 ELSE COMPUTE ส่วนลด = 0 END IF COMPUTE ราคาสุทธิ = ราคารวม - ส่วนลด OUTPUT ราคาสุทธฺิ END 3. เขียนพังงาน (Flowchart) (ให้นักเรียนวาดพังงานโดยใช้สัญลักษณ์มาตรฐานที่ถูกต้องตามรหัสเทียมที่ได้ออกแบบไว้ข้างต้น ลงในพื้นที่ว่างด้านล่าง หรือวาดลงในกระดาษฟลิปซาร์ทที่ครูเตรียมให้) โจทย์สถานการณ์ที่ 2: ระบบตรวจสอบการเข้าใช้งาน (Login System) รายละเอียด: ระบบบริหาร จัดการร้านค้าต้องการความปลอดภัย จึงต้องมีระบบ Login ให้ผู้ใช้ป้อน Username และ Password โดยมีเงื่อนไขการตรวจสอบคือ: ถ้า Username คือ "admin' และ Password คือ 12345" ให้แสดง ข้อความ "Login Success แต่ถ้าข้อมูลใดข้อมูลหนึ่งไม่ถูกต้อง ให้แสดงข้อความ "Login Failed" 1. เขียนรหัสเทียม (Pseudocode) // เติมคำสั่งให้สมบูรณ์ BEGIN INPUT Username INPUT Password IF Username = "admin" AND Password = "12345" THEN OUTPUT = "Login Success" ELSE OUTPUT = "Login Failed" END IF END 2. เขียนยังงาน (Flowchart) ให้นักเรียนวาดยังงานโดยใช้สัญลักษณ์มาตรฐานที่ถูกต้องตามรหัสเทียมที่ได้ออกแบบไว้ข้างต้น
